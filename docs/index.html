LANDING

Volume / ADLS Gen2

Raw TfL CSVs and BikePoint JSON. One config switch moves storage to Azure.

BRONZE

Auto Loader

Incremental, exactly-once file ingestion. Strings only, plus source file and ingest time.

SILVER

Typed and validated

ANSI-safe parsing, 8 validation rules, quarantine with reasons, MERGE on rental_id.

GOLD

Five aggregates

Daily KPIs, hourly demand, station flow, top routes, bike mix.

QUALITY

14 checks

Silver integrity plus gold reconciliation back to silver. Results stored in Delta.

GOVERN

Unity Catalog

Comments, tags, gold-only grants for analysts, automatic lineage.
